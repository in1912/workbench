# 个人工作台 · 使用说明（v1.6.3）

自托管效率中枢：信息聚合、待办日程、家庭管理、学习平台、AI 助手、三大测评中心、智作平台（文案库）、录音转写等，全部数据保存在自己电脑上。

## 一、快速开始（Windows）

1. **装 Node.js**（只需一次）：到 https://nodejs.org 下载 **Node.js 22 LTS** 安装（必须 22.5 以上版本）。
2. **解压本文件夹**到任意位置（如 `D:\personal-workbench`），路径不要带空格更省心。
3. **双击 `start.bat`**：
   - 首次运行会自动安装依赖（需要联网，约 1-2 分钟）；
   - 然后自动启动服务，浏览器打开 **http://localhost:3000**。
4. **登录**：默认账号 `admin`，密码 `admin123` —— **登录后请立即到「设置 → 修改密码」改掉**。

> macOS / Linux：终端进入文件夹执行 `npm install && node --no-warnings server/index.js` 即可。

## 二、换端口 / 局域网访问

- 换端口：命令行执行 `set PORT=3100` 后再运行 `start.bat`（或在 Docker 里改环境变量）。
- 手机 / 平板访问：手机与电脑连同一个 WiFi，浏览器打开 `http://<电脑局域网IP>:3000`（电脑 IP 在「系统设置 → 分享访问」页可查）。外网访问需自行配置内网穿透或使用 Docker + 反向域名。

## 三、数据在哪里 / 怎么备份

- 全部数据都在文件夹内的 `data/` 目录（账号、业务数据、证书）和 `zhizu/data/`（智作平台）。
- **备份 = 把整个文件夹复制一份**；恢复 = 拷回原位。
- 想完全重置成全新系统：停掉服务，删掉 `data/` 目录，重启即重建（默认账号重新变回 admin / admin123）。

## 五、常见问题

- **启动报 Node 版本错误**：装 Node.js 22 LTS（start.bat 会自动检测提示）。
- **端口被占用**：换端口（见第二节）。
- **忘记 admin 密码**：停服务 → 删 `data/workbench.sqlite` 会丢全部账号数据（不推荐）；更稳妥是提前在「设置 → 用户管理」里加一个备用管理员。
- **改了前端想重新构建**：命令行执行 `npm run build:web`（需要联网装前端依赖）。
- **Docker 部署**：`docker compose up -d --build`（见 Dockerfile / docker-compose.yml，数据落在 `./data` 卷）。

## 六、升级

拿到新版本压缩包时：停掉服务，把新包里的 `server/`、`web/dist/`、`zhizu/`、`web/public/` 覆盖到旧文件夹（`data/` 不要覆盖），再启动即可；也可在系统内「设置 → 系统升级」上传差分升级包完成自动升级。
