# 个人工作台（Personal Workbench）

自托管的个人/家庭效率中枢：信息聚合、待办日程、家庭与子女管理、学习成长、录音转写、AI 文案创作、心理测评、业务系统集成，全部数据保存在自己电脑上。支持 Windows 一键启动与 Docker 部署。

- **当前版本**：v1.6.3
- **运行要求**：Node.js ≥ 22.5（Windows 直跑）或 Docker
- **默认账号**：`admin` / `admin123`（首次登录后请立即修改）

### 智作平台（AI 文案创作）

以独立子进程嵌入（同源路径 `/zhizu`，数据隔离在 `zhizu/data/`）：AI 智能选题首页（单选行业 + 定时后台生成 + 逐条热点来源链接）、10 大创作功能、敏感词检测（原文保存 + 命中高亮对照）、15 部法规库、三角色权限（admin/user/guest）。

### 录音转写（VibeVoice）

- **服务器引擎**：Whisper large-v3-turbo（含 Docker 侧车），适合部署在有算力的服务器/NAS
- **客户端引擎**：1.5B 量化版（CPU 可跑）或 7B 完整版（需 NVIDIA 显卡，走 WSL2 + vLLM），一键部署包自动安装——转录算力落在自己电脑，服务器零压力
- 录音保存三节点进度条、转写实时进度（按历史耗时估算）、说话人分离

### 三大测评中心（私有项目）

MBTI 职业测试 / 抑郁筛查（PHQ-9 等）/ 心理测评：管理员可对每个中心独立生成**免登录分享链接**（支持自定义访问前缀域名）；「对外测试开关」一键停用后：新开页面立即 403，**已打开的页面也会在 15 秒内整页锁定**（运行时门禁，防止关开关后继续作答）。

## 快速开始

### Windows（推荐）

1. 安装 [Node.js 22 LTS](https://nodejs.org)（必须 22.5 以上）
2. 解压项目文件夹到任意位置（路径不带空格更省心）
3. 双击 `start.bat`：首次运行自动安装依赖并启动，浏览器打开 <http://localhost:3000>
4. 用 `admin` / `admin123` 登录，**立即到「设置 → 修改密码」改掉默认密码**

> 命令行方式：`npm install && node --no-warnings server/index.js`

### macOS / Linux

```bash
npm install
npm run build:web   # 首次或前端有更新时构建
npm start           # http://localhost:3000
```

### Docker

```bash
docker compose up -d --build
```

- `restart: always` 开机自启；数据落在宿主 `./data` 卷，升级/重建容器不丢
- 或用 `bash pack-deploy.sh` 生成全量部署包（含源码与数据目录）上传服务器

## 首次配置建议

1. **天气**：设置 → 输入城市名 →「保存并定位城市」（免费接口，无需 Key）
2. **AI**（可选但强烈建议）：设置 → 填模型名称 / API 地址 / API Key，任意 OpenAI 兼容服务均可；配置后新闻摘要、笔记总结、学习复盘、AI 助手、账单分类全部启用
3. **邮箱**：设置 → IMAP 服务器 / 账号 / 授权码（QQ、163 等均支持）
4. **新闻源**：内置实测可用的科技/生活 RSS；「本地」新闻建议替换为你所在城市的 RSS 源
5. **成员**：用户管理（仅管理员）添加账号并勾选可访问的页面与页签

## 访问方式

- **换端口**：环境变量 `PORT`（如 `set PORT=3100` 后再运行 start.bat）
- **局域网**：默认监听 `0.0.0.0`，手机/平板连同一 WiFi 访问 `http://<电脑IP>:3000`（本机 IP `ipconfig` 查看，或系统内「分享访问」页直接查看；Windows 首次需放行防火墙端口）
- **外网**：自行配置内网穿透或反向代理域名；内置 SSL 自签名证书工具（设置 → SSL 证书）可为局域网 HTTPS 访问签发证书

## 数据存储与备份（重要）

| 部署方式 | 数据位置 |
|---------|---------|
| 本地直跑 | `data/workbench.sqlite`（主库）+ `data/tenant-*.sqlite`（各成员租户库） |
| Docker | 宿主 `./data` 卷（容器内 `/data`） |

- **备份 = 复制整个 `data/` 目录**（外加 `zhizu/data/` 智作平台库）；恢复 = 拷回原位
- **完全重置**：停服务 → 删 `data/` → 重启（账号回到默认 admin/admin123）
- ⚠️ 切勿把 `data/` 放在云同步盘（OneDrive / 坚果云 / Synology Drive 等）目录下——同步锁文件会导致 SQLite 写入失败；自定义位置用 `DATA_DIR` 环境变量指向非同步目录

## 多成员（多租户）

系统支持类 SaaS 多成员，管理员建账号后每个成员是独立"租户"：

- **完全隔离**：笔记/待办/日程/邮箱/文件/AI 对话/账单/学习/家庭档案/业务系统与 Skill/看板布局等
- **可共享模块**（管理员开关控制，默认全开）：新闻抓取、节日、地图 Key、AI 配置——共享时管理员统一配置，全员同享
- 删除成员时其租户库自动归档到 `data/archive/`，可恢复

## 版本升级

**方式一（覆盖升级）**：拿到新版本包后停服务，把新包的 `server/`、`web/dist/`、`web/public/`、`zhizu/`（不含 `zhizu/data/`）覆盖到旧文件夹——`data/` 永不覆盖——再启动。

**方式二（系统内差分升级）**：本地工作台「设置 → 系统升级」检测改动 → 打包（源码 + 前端构建快照 + manifest）→ 下载 zip → 目标机工作台上传应用，服务自动重启生效。升级日志全程记录版本号与内容，两端可见当前运行版本。

## 技术架构

```
Vue 3 + Vite（SPA 单页应用，Material Icons）
        │ REST API（同源部署，hash 路由）
Express + node:sqlite（主库 + 租户库多库架构）
        ├── 智作平台子进程（Express，127.0.0.1 回环通道，同源 /zhizu 反代）
        ├── 转写引擎边车（Whisper / VibeVoice，服务器或客户端算力）
        └── node-cron 定时任务 · rss-parser · imapflow · Open-Meteo · OpenAI 兼容 AI
```

## 常见问题

- **启动报 Node 版本错误**：装 Node.js 22 LTS（start.bat 自动检测提示）
- **端口被占用**：换 `PORT` 环境变量
- **忘记 admin 密码**：更稳妥是提前在「用户管理」加备用管理员；极端情况删 `data/workbench.sqlite` 可重置（丢全部账号数据，不推荐）
- **新闻抓不到**：容器/本机需能访问外网；个别 RSS 源失效可在设置替换；本地新闻依赖天气城市
- **邮件连不上**：确认邮箱已开启 IMAP（993/TLS）；QQ 等需在邮箱设置开启服务并使用授权码
- **AI 报错**：base_url 需以 `/v1` 结尾（如 `https://api.deepseek.com/v1`），模型名与服务商一致
- **改前端后重新构建**：`npm run build:web`（需联网装前端依赖）
- **测评中心分享链接打不开**：管理员可能已关闭「对外测试开关」；开启后旧页面需强刷（Ctrl+F5）

## 安全说明

- 密码 scrypt 加盐哈希存储，登录失败连续多次自动锁定
- 页面/页签双层权限控制，管理员可精确分配每个成员的可见范围
- 测评中心对外分享默认关闭，开启后可随时一键停用（含运行时锁定）
- 业务系统凭据加密存储；日志不落敏感信息
