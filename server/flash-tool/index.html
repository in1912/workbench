烧录前请先确认

  1. 用 Chrome 或 Edge 打开本页（Firefox / Safari 不支持网页读串口）。
  2. USB 数据线直接插电脑（不是只能充电的线），板子通电。
  3. 第一次插板子如果设备管理器里是感叹号，先装下面这个串口驱动。
  4. 烧录过程中不要拔线、不要关这个页面。
串口驱动（CH343，智能板用）： 下载安装程序 SETUP.EXE —— 下载后双击、点「安装」、插拔一次 USB 即可。 红绿灯（ESP32-C3）不需要额外驱动，Windows 10/11 自带。
