JARVIS 烧录工具包（网页版）
========================================

给谁用
------
想把「智能板（小智 Korvo2V3 / ESP32-S3）」或「Agent 红绿灯（ESP32-C3）」刷上固件的人。
不需要装 Python、不需要敲命令行 —— 双击一个文件，浏览器里点几下就烧完。


怎么用（三步）
--------------
1. 把整个压缩包解压到一个文件夹（别在压缩包里直接双击，会找不到固件文件）。

2. 双击  启动烧录.cmd
   → 会自动起一个只监听本机（127.0.0.1）的小服务，并自动打开 Edge / Chrome。
   → 如果浏览器没弹出来：手动打开 Edge/Chrome，地址栏输入窗口里提示的那一行
     http://127.0.0.1:xxxxx/index.html

3. 在网页里：
   智能板： 插好板子 → 点「① 选择串口」选中板子的口 → 点「② 开始烧录」→ 等进度条走完
   红绿灯： 插好板子 → 点「① 选择串口」→ 点「② 一键烧录」
            → 烧完板子会自动重启，串口要重新选一次 → 点「③ 继续写入程序」

   烧完直接关掉那个黑色窗口就行。


必须知道的两件事
----------------
· 只能用 Microsoft Edge 或 Google Chrome 打开本页。
  Firefox / Safari / 各种「兼容 IE」的浏览器都没有「网页读串口」这个能力，页面会直接提示不支持。

· 串口驱动：智能板的 USB 转串口芯片是 CH343，Windows 可能不认。
  认不到的表现在「设备管理器 → 端口」里没有 COM 口，或者有个带感叹号的设备。
  解决办法：装 driver\ch343-driver\CH341SER\SETUP.EXE，装完拔插一次 USB。
  红绿灯（ESP32-C3）用的是芯片自带的 USB，Windows 10/11 免驱，不用装。


常见问题
--------
Q: 提示「连不上板子 / 等待响应超时」
A: 依次检查：
   ① 数据线是不是只能充电的线（换个能传数据的）；
   ② 板子有没有上电（有的板子要单独供电）；
   ③ 串口是不是被别的软件占着（串口助手、Arduino IDE、PlatformIO、另一个烧录窗口）；
   ④ 智能板可以试试点住板子上的 BOOT 键不动，再点「开始烧录」，进度条起来后再松开。

Q: 选串口的时候列出来好几个口，选哪个？
A: 拔掉板子看哪个口消失了，就是它。或者看看口后面的芯片名（CH343 / USB JTAG）。

Q: 智能板烧完要不要重新配网？设备绑定还在吗？
A: 不用、还在。这个包用的是**分段烧录**，不会碰 nvs 分区（配网信息、设备绑定都存那儿）。
   注意：网上有些教程让你烧 merged-binary.bin（合并固件），那个会把 nvs 一起清掉，
   配网和绑定全丢 —— 本工具刻意不这么做。

Q: 红绿灯「继续写入程序」这步能跳过吗？
A: 不能。第一步刷进去的是 MicroPython 运行时（相当于装了个操作系统），
   第二步写进去的 main.py 才是灯效程序本身。两步都做完灯才会亮。

Q: 红绿灯想改成自己的灯效怎么办？
A: main.py 就在 firmware\cclight\ 目录里，是明文 Python，改完重新跑一遍烧录即可。
   也可以单独只跑「③ 继续写入程序」那一步，不用重刷固件。

Q: 烧完了想验证一下
A: 红绿灯：板子上电后会在电脑蓝牙里广播，名字里有 Agent light；灯亮起来就说明对了。
   智能板：唤醒后（默认「小阳阳」）能应答即正常；板子会自己连回你的 JARVIS 应用。


这个包里的东西
--------------
启动烧录.cmd        双击入口
serve.ps1           本地静态服务器（PowerShell，只监听 127.0.0.1，不联网、不外传）
index.html / app.js 烧录页面（Web Serial）
vendor/             esptool-js（Apache-2.0，烧录引擎，已内联全部依赖，运行期不访问外网）
firmware/xiaozhi/   智能板固件（5 个分区文件 + 偏移量在 manifest.json 里）
firmware/cclight/   红绿灯固件（MicroPython .bin + main.py）
driver/             CH343 串口驱动

安全说明
--------
· 本地服务只绑定 127.0.0.1（回环地址），同一网络里的其它机器访问不到。
· 页面不上传任何东西，不访问外网；固件全部来自本文件夹。
· 页面能读的只有你亲手在弹出的系统窗口里选中的那一个串口。
