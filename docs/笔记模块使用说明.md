# 笔记模块使用说明（v1.9.41）

工作台的笔记从这一版起是一套**知识系统**：三栏布局 + 双链 + 知识图谱 + 白板 + 数据库查询 + 时间线 + 统计 + 每日笔记。这一页讲清楚「怎么用」，浏览器里同一份内容在笔记页左栏「❓ 说明」里也能看（那份还会读运行时的快捷键表，永远比文档新）。

---

## 一、界面：三栏

| 栏 | 有什么 |
| --- | --- |
| 左 | 分区切换（文件 / 搜索 / 标签 / 书签 / 模板 / 录音）+ 文件夹树 + 底部视图入口（图谱、时间线、数据库、白板、说明）与「今日 N 字 · 连续 N 天」 |
| 中 | 页签条 + 编辑器（编辑 / 分屏 / 预览）+ 各视图页（图谱 / 白板 / 时间线 / 数据库 / 统计 / 说明） |
| 右 | 大纲 / 属性 / 链接 / 统计 四种模式 |

分隔条可以拖动，宽度记住；窗口窄于 900px 时右栏收成抽屉。顶部页签可同时开多篇笔记，切回来不重新加载；关未保存的页签会拦一下。

---

## 二、文件夹与标签：一个管"在哪"，一个管"是什么"

- **文件夹是一棵树**，可以多级（`工作 / 2026`），一篇笔记只属于一个文件夹。拖动笔记就能换文件夹。
- **标签可以有任意多个**。正文里写 `#物理` 就算打上标签（行首 `# 标题` 不会被误认），右侧「属性」里也能手动加。
- 老的「分类」已经并入这棵树，历史上的分类名就是现在的顶层文件夹，**外部写入令牌跟着文件夹走**，已经发出去的写入地址不会失效。
- 闪念 / 文献 / 永久笔记**不做成硬性类型**，用「模板 + 标签」组合：先选模板建笔记，再让它带上对应标签。

---

## 三、双链：`[[另一篇的标题]]`

- 正文里写 `[[某标题]]` 就建立了链接。目标存在 → 点进去；**不存在也不会丢**，右侧「链接」面板的**未解析**里会列出来，点一下就能建出那篇。
- 笔记改名会留下**别名**，老的 `[[旧标题]]` 不会断。
- 引用关系在右侧「链接」面板看：出链（我指向谁）/ 反链（谁指向我）。
- 同名笔记会让链接有歧义（取第一条），起标题时尽量错开。

---

## 四、搜索

四种模式，左栏「搜索」分区切换：

| 模式 | 说明 |
| --- | --- |
| 关键词 | 标题 + 正文 + 标签模糊匹配，中文直接子串，不需要分词 |
| 标签 | 按标签精确找 |
| 路径 | 按所在文件夹找，默认连子文件夹一起算 |
| 正则 | 跑在后台线程里，带 1.5 秒硬超时；长度 >200、嵌套量词等危险模式会被直接拒绝 |

搜索不做 FTS5 全文索引——个人量级（几千条）`LIKE` 全扫是个位数毫秒，引全文索引反而要在三个写入路径上同步影子表。笔记超过两万条再回头考虑。

---

## 五、数据库视图（Dataview）

两种写法等价：**表单**里一行一个条件，或**文本**里直接写：

```
title ~ "周报" AND words > 200
```

- 字段：`title / content / tag / folder / category / created / updated / bookmarked / words / prop.属性名`
- 操作符：`= != ~ > < >= <=`
- 连接词：`AND` / `OR`，最多 10 个条件（表单模式是一个全局连接词，因为后端只支持一层）
- 结果表格里可以直接改属性值，也能「复制表格」成 Markdown 贴进笔记。

属性（自定义字段）在「属性定义」里先建好：`文本 / 数字 / 日期 / 单选 / 复选框`，建好后右侧「属性」面板就能填。

## 六、图谱怎么看

- 颜色 = **顶层文件夹**；连线 = 双链。
- **空心灰点** = 孤岛（没有任何链接进出的笔记）；**带白环的点** = 枢纽（被引用次数在前 10%，样本太少时不标）。
- 滚轮缩放（以光标为中心）、拖空白平移、拖点钉住；单击打开笔记，双击进入它的**局部图**（N 跳邻居）。
- 顶栏：只看孤岛 / 居中集散点 / 释放钉住 / 适配窗口 / 按文件夹筛选 / 只看标题含某词。

图是 `d3-force` 算布局 + Canvas 2D 自绘：算完 300 拍就停下来，静止时不吃 CPU；超过 800 个点时自动省掉碰撞与标签。

## 七、白板

- 卡片有四类：**笔记卡**（显示笔记最新标题与摘要，点开就是原笔记——是活链接不是复制品）、**文本卡**、**图片卡**、**链接卡**。
- 加卡片：顶栏按钮，或从「＋ 笔记卡片」下拉里挑一篇。
- **连线**：从卡片右边缘的小圆点拖到另一张卡片。
- 拖动 / 缩放 / 改大小后**自动保存**（防抖 0.8 秒）；视口位置也存，刷新回来还是那个样子。撤销 50 步（只记增 / 移 / 删这类结构变化）。
- 这一版**不做**：网页卡片内嵌 iframe（会被目标站的 X-Frame-Options 挡）、旋转、分组、画框、多人协作。

---

## 八、每日笔记

- 左栏「今日笔记」或 `Ctrl/⌘ + P` 打开今天的日记；**同一天只会有一条**（并发下靠 `daily_date` 的部分唯一索引兜底）。
- 「设置」里可以指定**自动创建**与**默认模板 / 默认文件夹**；打开自动创建后，服务器每天凌晨会替你把当天那篇先建好（按天幂等，重复跑不会多出第二篇）。
- 模板占位符：`{{date}}` `{{time}}` `{{title}}`。

## 九、插件

| 插件 | 在哪 | 作用 |
| --- | --- | --- |
| 统计 | 左栏底部细条 / 「📊 统计」视图 | 今日字数、总字数、连续与最长打卡、每日字数曲线、文件夹分布 |
| 日历 | 日程页右上角「显示笔记」开关 | 每天格子里补上当天写过的笔记标题，点标题跳过来；没有笔记权限时静默不显示 |
| AI 辅助 | 笔记头部「AI ▾」 | 总结 / 续写 / 翻译，结果可插入光标处或整篇替换 |

## 十、快捷键

| 键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + O` | 快速切换笔记（匹配不到可以直接新建） |
| `Ctrl/⌘ + Shift + P` | 命令面板（所有功能入口） |
| `Ctrl/⌘ + P` | 打开（必要时创建）今日笔记 |
| `Alt + N` | 新建笔记 |
| `Ctrl/⌘ + S` | 保存当前笔记（编辑区里也生效） |
| `Ctrl/⌘ + F` | 跳到左栏搜索 |

> 只有**拦得住**的组合才注册。`Ctrl+N` / `Ctrl+W` 是浏览器窗口级的，`preventDefault` 无效，所以没占用——否则顺手一按就把整个工作台关掉了。
> `Ctrl+P` 在笔记页里被占成了「今日笔记」，要打印请用浏览器菜单。
> 在编辑框打字时，只有明确标了「编辑区可用」的快捷键会触发。

---

## 十一、外部写入与分享

- 文件夹可以生成一个**只写令牌**：外部系统 POST 内容进来就自动变成该文件夹下的笔记（免登端点，未授权一律 403/404，绝不返回 401 去触发登录跳转）。
- 单篇笔记可以生成**分享链接**（可设密码），在 `/s/<token>` 公开只读访问。
- 这两条来源都不可信，所以渲染时会压掉原始 HTML 并清洗脚本 / 事件属性 / `javascript:` 链接。

---

## 十二、备份与数据

- 每个用户一个库：`data/tenant-<uid>.sqlite`（主库 `data/workbench.sqlite`）。备份直接拷这两个文件即可（记得先停服务，或用 SQLite 的在线备份）。
- 删笔记会级联清掉它的分享、链接、标签、别名、书签、附件，并把指向它的 `[[标题]]` 退回「未解析」——**绝不碰录音记录与音频文件**，那些还在「效率工具 → 录音转写」里。
